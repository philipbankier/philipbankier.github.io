# What reads as generic: the audit

- all: The four mockups map almost one-to-one onto the five generic AI clusters that Anthropic's own frontend-design SKILL.md now tells Claude to avoid. Cluster 1 (warm cream plus serif display plus one accent) is plates (#F4EFE3 + Fraunces + #2240C8) and plumber (#E9DFC6 + rust #B5351B). Cluster 2 (near-black with acid green) is phosphor (#070A08 + #3BFF9E). Cluster 3 (broadsheet hairlines, zero radius, dense columns) is swiss. Cluster 5 (ALL-CAPS labels, middle-dot metadata, monospace for data) is all four. That explains the client's 'standard Claude design output' verdict. Source: https://raw.githubusercontent.com/anthropics/claude-code/main/plugins/frontend-design/skills/frontend-design/SKILL.md
- all: All four are one template in four skins, with an identical DOM order: strip or masthead, then a hero (name, bio, three CTAs), a six-row ledger with a → per row (plumber .arrow-cell, swiss .a, phosphor .go), a three-up product row (ActRun / PromptCache / Kairox AI), a 2x2 papers grid, and a multi-column link footer. signs-of-ai-design (github.com/febbhav/signs-of-ai-design) calls this 'the cookie-cutter page order'. Hallmark's diversification rule exists to stop exactly this: pages that feel like 'colour-swaps of the same template'.
- all: IBM Plex Mono is loaded in all four files and drives every micro-label at 9.5 to 12px, uppercase, letter-spacing .14 to .34em: plates .half-title .34em and .plate-no .3em, phosphor .sec-bar h2 .3em, plumber .stamp .22em and th .18em, swiss .mast .06em and .k .12em. Mono uppercase letter-spaced labels are the most-cited tell: Krebs lists 'All-caps section labels', signs-of-ai lists 'Monospace as decoration', and SKILL.md lists 'All caps for labels'.
- all: Every file has numbered or catalogued section markers. Plumber: boxed 01 to 04, R07 to R12, ASM-000 to 002, DWG-01 to 04. Swiss: 001 to 006, W.01 to 03, P.01 to 04, 'Index Nº 01'. Phosphor: CH-00 to 02, DOC-01 to 04. Plates: Plate I to III, roman vi to i, № 1 to 4. Hallmark sets 'Section tags / eyebrows: default OFF' and auto-fails the tag-left/heading-right hanging header (gate 54). That's plumber's .sec-head (boxed number, title, arrow rule) exactly.
- all: Middle-dot metadata appears everywhere: 'DWG · PB-2026 · SHEET 1 OF 1', 'Co-founder · Kairox AI', 'ASM-001 · In service', 'CH-01 · In service', 'Kairox AI · 2026', 'Philip Bankier · Collected works', and all four <title> tags. SKILL.md cluster 5 names 'middle-dot metadata' specifically.
- all: The motion is the generic set or nothing. Plumber and swiss put opacity 0 plus translateY(18 to 26px) on animation-timeline: view() for every .reveal, and swiss adds the stock line-mask slide-up on the H1. Phosphor has a 900 ms count-up and a blinking cursor. Plates has zero scroll motion and only a Fraunces SOFT-axis hover on the H1. Nothing responds to the cursor beyond colour-swap hovers. SKILL.md says to avoid 'fade-and-slide-up entrances on each section', and signs-of-ai lists 'The same fade-in on everything'.
- all: The portrait gets CSS filters plus a pseudo-element overlay inside a bordered box, with a 'FIG.' caption claiming a process that isn't happening. Plumber's 'HALFTONE · 65 LPI' is a 4px radial-gradient dot grid at mix-blend overlay over grayscale, which reads as a screen door, not a halftone. Plates' 'Gravure · one color' is grayscale plus a blue screen blend at .34. Phosphor is a green gradient screen. Swiss shrinks him to a 260px grayscale thumbnail captioned 'FIG. A'. This matches tailthemes' 'underfunded design ideas' tell: the rationale is named but the effect isn't built.
- all: There's a three-item product row in all four (.assemblies, .works, .channels and .placards are all repeat(3, 1fr)), plus three hero CTAs in plumber, phosphor and plates. The three-card row is the most widely mocked layout tell, and it also breaks the brand's own 'no three-item parallel triplets' rule.
- all: Each page has one static texture plus one accent hue: feTurbulence grain at .07 (plumber) and .05 (plates), 1.2%-white scanlines (phosphor), fixed column hairlines (swiss). None of them move or react to anything. Grain overlay plus a single accent is the 2025 default.
- all: The metaphor lives in copy labels, not visuals: 'Checked by: The agents', 'Hail on any channel', 'Exhibited continuously. Admission free.', 'Schedule of work / Assemblies / Drawings on file', 'Tape log / Channels / Papers on file'. Renaming sections is cosplay. Every reference that owns one of these aesthetics builds a working object inside it.
- plumber: Specific tells include the manila #E9DFC6 drafting grid (four static linear-gradients), a rust-red rubber stamp rotated -2deg with an feTurbulence mask plus a scale 'thunk', an outline-stroked surname (-webkit-text-stroke 2.5px), and a double fixed border frame inset 14px. Add a decorative 'Drawn by / Checked by / Date / Rev' title block, dimension lines that measure nothing ('EST. FLOW ... CONTINUOUS'), outlined chip tags ('Field brief', 'Roundup') on 2x2 bordered drawing cards, generic valve SVGs pinned top-right of each product card (icon in the card corner), and a 2fr/1fr/1fr/1fr footer. Every drafting element is static decoration, and none of them is a drawing of anything Philip built.
- swiss: Specific tells include Inter Tight (Inter family, the most-cited AI font) set huge in uppercase with a 200/840 weight split inside the name (the sans version of the single-word accent), a red period, and a mono kicker above the H1 ('The work, indexed. 2026 edition', which is Krebs' 'badge above H1'). Also a lede with one phrase underlined in red, four fixed hairline column rules, an index table that hover-inverts to black, a live clock in the masthead, and a giant clipped 'Index.' footer word. It also breaks the brand rules: visible em dashes in '001—006 · REBUILT DAILY', 'W.01—03' and 'P.01—04', and a triplet in the blockquote ('the repos, the products and the writing').
- phosphor: Specific tells include permanent dark #070A08 with acid green #3BFF9E plus amber, and text-shadow glow on the H1 and meter values (Krebs' 'colored glows', signs-of-ai's 'neon-on-dark with glow'). The type is mono only. A 4-up stat banner has count-up numbers and arc gauges whose fill (stroke-dasharray 78/60/45/88) is arbitrary and unrelated to the values, which is signs-of-ai's 'animated stat counters and implausible numbers'; 'Products in service: 3' counts the site itself. There's a fake status bar ('All systems in service' with a glowing lamp), a blinking 'Feed · live' cursor on a static list (a fake terminal), and eight identical 1px #1B2620-bordered panels (ghost cards). The 1.2%-white scanline overlay is too faint to read as CRT.
- plates: Specific tells start with bone #F4EFE3 and Fraunces display with the surname in blue italic ('Philip <i>Bankier</i>'), followed by the same italic-accent move three more times ('The <i>record</i>', 'The <i>works</i>', 'The <i>papers</i>'). That's Hallmark gate 38a ('An italicised emphasis word inside an otherwise-upright heading is one of the most reliable AI tells') and Krebs' 'serif italic accent words'. Also: everything centred (cover, plate heads, colophon), a ◆ ornament rule, a soft 0 16px 40px drop shadow on the portrait mat, placards that lift translateY(-4px) with a shadow on hover (the SaaS card hover), a mono uppercase .34em half-title, and symmetric italic side captions flanking the portrait. The right caption is a three-sentence triplet ('Products by... Writing at... Code in the open at...').
- all: Field data: Adrian Krebs scored 1,590 Show HN sites with deterministic DOM/CSS checks (333 points on HN). 22% hit 4 or more patterns. His diagnostic list includes all-caps section labels, badge above the H1, serif italic accent words, coloured glows, stat banner rows and numbered step sequences. Every mockup trips 4 or more. https://www.adriankrebs.ch/blog/design-slop/
- all: These aesthetics are now off-the-shelf presets. The Hallmark anti-slop skill ships 'Terminal', 'Riso', 'Newsprint', 'Specimen', 'Grid', 'Almanac' and 'Brutal' as catalog themes, and a 3.3k-star agent skill (github.com/yanliudesign/mono-color-skill) generates 'warm paper, halftone photography' on demand. Choosing a period style no longer differentiates anything. The bar is a built, interactive artifact inside the style.
- all: What separates the references is that each one renders a real object in its style and makes it respond. Oxide's green-on-black earns its look with a CLI typing real commands, leader-lined to a three.js rack captioned 'FIG. 1'. GT Mechanik's drafting diagrams are working controls. Stripe Press's engraved portrait sits on a 3D book that turns and floods the page with its colour. Ciechanowski's watch explodes on a slider. The mockups have the caption but never the figure.
- all: For the low-res portrait, make the treatment's resolution the aesthetic, so 449x561 is more than the treatment needs. A 3 to 4px dither cell, a 60 to 110-line engraving, a 96x120 ASCII grid and a vector beam all need less than 449px of information. Then give the cursor a lens that changes the treatment locally, like Lando Norris's cursor ring revealing the helmet under the face. CSS filter stacks can't do either.
- all: Use one orchestrated signature moment per direction, driven by real data rather than decorative numbers. Plumber: the ActRun assembly explodes on scroll, and ledger entries flow as pressure pulses into the schedule. Swiss: the name collapses into the masthead along a variable-font axis, and index rows morph into paper pages through cross-document View Transitions. Phosphor: a beam traces his name with persistence, then the tape log boots row by row with glyph scramble. Plates: the portrait engraves in on scroll, and each paper is a 3D book that turns. SKILL.md says 'A single orchestrated moment...lands better than scattered effects'.
- all: Stack check for GitHub Pages. The live award-tier sites I verified run on three.js plus Lenis on Webflow (Lando Norris, r174), hand-rolled WebGL (Ciechanowski, no library, 93 canvases), three.js r151 (Stripe Press), or zero-canvas CSS scroll timelines plus View Transitions (Cyd Stumpel). All of them work as static hosting. Don't depend on HTML-in-Canvas (Codrops, 2026-05-13), which is still behind chrome://flags/#canvas-draw-element. Don't use Paper Shaders' mesh or grain gradients, which are slop staples; use only its image filters.
