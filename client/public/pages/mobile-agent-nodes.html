Inspect what the tool can see

Accessibility trees can provide element labels and structure. Their completeness varies by app, so screenshots and observed results still matter. Mobilerun’s device documentation notes incomplete trees in WebViews, games and custom-rendered interfaces.

For an evaluation, choose a read-only task in the app you intend to use. Check whether the tool identifies the intended element and whether the observed screen agrees with its report. Treat a supported platform as the start of testing, not proof that a particular app workflow succeeds.

This guide reviews documentation. It does not report a physical-device acceptance test.

Follow the selected tool’s setup guide

Use its current instructions for your host and target. Start with a read-only device exercise before attempting changes.
