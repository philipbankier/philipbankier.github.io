What Glance is

An open-source Python harness (glance-vlm) that asks a local open vision-language model typed questions about an image and returns probabilities from one forward pass. Default backbone Qwen3-VL-4B. Nothing is generated or trained; optional hosted demos send images to the cloud. Project claims recognition near best hosted models on fresh photos, with geometry still weak and ratings improved by few-shot rubric fits.
